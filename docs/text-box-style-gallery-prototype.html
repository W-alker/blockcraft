让信息像空间一样清晰

文本框不只是容器，它可以承担引言、侧栏、信息强调和章节提示。好的样式应当让内容层级更明确，同时保持文档的专业感。

设计让重点自然浮现

用克制的色彩、清晰的边界与适量留白，把读者带到最重要的信息上。

样式库采用“主题色 + 预设”的方式组织。换一套文档主题时，同一预设仍应保持角色一致，而不是固化为某一种品牌颜色。

交互说明：选择样式不会改变文本内容；横排/竖排仅切换 frame writing mode；正文可直接编辑，用来观察真实文本长度下的留白和可读性。
