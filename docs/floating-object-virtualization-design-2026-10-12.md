# 浮动对象按尺寸模式挂载

日期：2026-10-12。用户已确认：固定尺寸按坐标虚拟化，自适应尺寸常驻。

## 领域与职责

- Document 的 Yjs / ModelGraph 始终保存完整对象树，不改变快照与坐标。
- Placement 可见性索引维护真实包围盒、固定对象区间树与常驻对象集合。模型或表面几何变化时更新；滚动只查询索引。
- Virtualization 合并可见对象、常驻对象与选区、导航、视图租约；全量视图租约与异常降级完整挂载。
- DocVM 只对根级 placement-layout 的直属对象使用稀疏投影；对象内部子树仍原子挂载。DocCRUD 同步模型顺序与跨父级所有权，不为离屏插入强制创建组件。
- TextContentAutoFit 保留 CSS 按文档/帧批量测量和派生 textFit 写入，移除保守范围与测量有效性缓存。

## 规则与影响

固定对象按根内容坐标、真实尺寸和旋转包围盒判断可见性，预挂载上下各一个视口。自适应文本对象与包含自适应成员的组合常驻；隐藏修订对象不因此挂载。普通文档流与其容器原子规则不变。

浮动对象离屏后释放组件，避免浮动层内部另建不受限缓存；既有 retainedViewLimit 仍控制根子树缓存。keep-alive/交互租约优先，引用组合成员时挂载其整体。组件销毁清理订阅和测量任务。

显式请求 placement-layout 视图表示请求完整子树；完整文档租约同样挂载全部固定对象。常驻策略不扩大分页或滚动高度：文档底边仍来自真实尺寸。只读对象常驻但沿用已有尺寸，不产生模型写入。

主要风险是跨父级移动/撤销的视图所有权、IME 中的同父排序、选区与导航对深层对象的同步访问，以及根窗口稳定时遗漏浮动子窗口变化。需沿既有模型事务和稀疏渲染 API 解决，不引入宿主特判。

## 验证

定向单测覆盖区间重叠/旋转/模式切换/隐藏修订及不变滚动无模型扫描；VM/CRUD 与虚拟化既有测试检查完整渲染、移动、撤销、租约、销毁。真实浏览器检查同一浮动层混合固定与自适应对象、底部向上滚动、离屏内容变更、组合、全量租约与可见 DOM 顺序。执行构建门禁和规模测试，单独报告未验证平台。
