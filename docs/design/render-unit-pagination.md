# 填写区与高亮块跨页设计

日期：2026-10-07

## 领域与边界

- Document / Block 保留原填写区、子块 ID、Yjs 树、尺寸和填写区元数据；分页不产生 Undo 记录。
- Pagination 测量填写区自然高度和子块安全边界，纯引擎仍只接收根块高度与切点。一个填写区对应多个页面片段。
- Inline 继续拥有长文本的零模型长度页缝与光标映射。分页通过既有内部 access 调用，禁止复制可编辑 DOM。
- View 负责可撤销子块间距、表格行断点及填写区分页占位透明裁切；退出分页、重测、失败回滚和虚拟化卸载均清理投影。

## 行为

分页模式下根级填写区以及旧快照中已存在的直接嵌套填写区展开内容，保留宽度，手动高度不回写。关闭分页恢复原尺寸。能放下一页的填写区仍整体放置；超页填写区按子块边界拆分。短文本和原子对象保持整体；超页文本使用现有安全行锚点；普通表格使用现有行边界与合并单元格保护。高亮块（Callout）复用 `container-pagination.ts` 的顺序流路径：当前页容不下则整体下移，超出整页容量时也先下移到新页，再按安全子块/文本行拆分。高亮块的内边距来自 Emoji/content 的共同外层，原 flex 布局保持不变；Emoji 不在续页重复。只沿填写区与高亮块的直接顺序子树递归，短高亮子块保持整体；Schema 子块白名单、分栏和表格单元格的边界不变。

屏幕页面与稳定打印布局使用相同像素切点；打印使用只读原始内容的片段窗口。页缝不进入模型、剪贴板和持久化数据。测量只在超页填写区展开，复用既有测量缓存、ResizeObserver 回声抑制、逐帧合并重排和 IME/指针锁。

分页占位带统一透明裁切，透出纸张、页眉页脚、页边距和既有纸张阴影；不额外测量或填充页内剩余高度。`--bc-region-pagination-clip` 是投影私有状态，不是宿主主题配置；清理时恢复原值。遮罩保留外伸手柄，表格全屏的既有祖先隔离标记会暂时撤销该裁切。

## 验证

定向单测覆盖引擎策略、复合锚点、几何索引、测量缓存、投影撤销/回滚、分页样式、稳定打印及离线导出。浏览器用真实文字矩形、页缝与边框几何和点击输入验证根级/旧快照直接嵌套填写区、多段文本、长文本、普通表格、固定高度、分页开关、75%/125% 缩放及撤销，并验证高亮块优先整体下移、超页拆分、直接嵌套填写区及 Emoji 保留。

Chromium、Firefox、WebKit 均运行填写区测试，另外运行 Chromium 的超高表格单元格分页编辑回归。打印验证覆盖导出 DOM 及片段完整性；不将其视为宿主 Tauri、下游安装包或实际打印设备验收。
