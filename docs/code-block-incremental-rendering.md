# 代码块增量高亮与渲染设计

日期：2026-11-06

## 目标与领域边界

高亮计算复用逻辑行分段，DOM 使用每显示逻辑行一个 `c-line`，保持一个 Block、一个 Y.Text、一个编辑面和现有块内 UTF-16 坐标。不调整快照、协同、撤销或分页的数据协议。

- Document/Input：继续负责 Yjs 事务、选区和 CompositionSession，不持有高亮缓存。
- Code：持有每个 runtime 独立的语法行缓存，处理语言/主题失效及跨行语法传播。
- Inline：Blot 的扁平字符索引不变；可选 `LogicalLineDom` 拥有持久行容器，canonical mutation 同时维护叶子和行结构。修订和用户颜色是词法结果上的独立展示投影。
- Selection：Mapper 识别由 ScrollBlot 注册的行容器，行边界换算为原有字符偏移；不引入行号选区坐标。
- Theme/Snapshot：共用 `c-line` 结构及 CSS counter，不计算或保存数字行号。

逻辑行缓存是派生状态，可以随时丢弃并从模型重建。异步任务用 runtime 代际取消；缓存不作为协同位置引用或文档数据保存。

## 已确认的影响范围

`CodeInlineRuntime` 由代码块和 Mermaid 源码编辑共用。代码块启用行 DOM，Mermaid 的 `withLineBreak:false` 保留原平面结构和整体投影。只读 Snapshot Viewer 的初始内容与异步高亮也生成 `c-line`，其 token 投影复用纯计算 helper，避免复制一份换行属性逻辑。

原先 `render()` 先同步重建模型 DOM，再由异步高亮重建一次，IME 提交和取消也经过这条路径。现在已准备好语法引擎和行基线的代码块，在组合输入结束的同步 `render()` 中按行恢复当前模型；后续帧检查并修复原生尾部输入，不再重复整块重建。首次加载、语言/主题刚切换及不支持的结构保留全量兜底。`applyDelta()` 走普通 InlineRuntime 增量更新，文本通知另行触发 debounce。debounce 默认同时启用 leading/trailing，首次输入可立即高亮，连续输入才合并尾部请求。

共享路径调查确认：原 ScrollBlot 部分插入操作假设 ref 在根下，分页撤销只认可直接 Blot 子节点，Mapper 假设首子节点是 gap。新增行模式由代码块明确启用；这些路径分别适配实际父节点、canonical topology 和已登记行边界，默认平面模式保持。EditableBlockComponent 的完整一致性检查继续保留。代码块仍是不可跨页拆分单元。

## 第二阶段：源逻辑行索引（2026-11-06）

本阶段只优化已挂载代码块的局部编辑，不引入虚拟行，也不改变文档模型、输入或历史协议。
调查确认，普通单行修改仍触发全部叶子的索引重建、显示行分组、DOM 文本读取和位置扫描；
这些是 Inline 投影的成本，应由 Inline 管理缓存，而不是由 Code 或 Input 维护第二份正文。

- **Inline**：仅 `c-line` 模式建立源逻辑行索引。源行按所有 LF 分段，显示行仍按可见 LF 分段；
  隐藏修订换行可令多个源行共享显示行。行记录保存实际叶子、文本与长度，行级前缀索引用于位置查找。
  单源行且不改变换行结构的修改只更新该记录和所在显示行；跨行、布局和未知结构沿用完整路径。
- **Code**：复用可信源行的文本和叶子边界，消除每次高亮对全部叶子的重新分组和文本读取。
  语法状态传播和原生 IME 完整性恢复规则保持，不能因为语法指纹相同就忽略原生 DOM 污染。
- **Selection**：通过包内能力访问节点对应 Blot、字符偏移和下一叶子。公共 UTF-16 坐标、
  换行 affinity、embed gap、分页和 fragment 边界语义保持；不可信时使用既有扫描。
- **Block**：仍将当前完整 Y.Text 内容与实际投影全文严格比较。仅可信纯文本行缓存可替代逐叶读取 DOM；
  不把 delta 镜像、相同长度或局部相等当作全文一致的证明。

缓存的信任边界由 Inline 持有：每个读取/受控修改入口同步检查 MutationObserver 的待处理记录，
未归因的原生文字、属性或结构变动立即使索引能力和缓存文本失效。受控修改只消化自身记录；
失败和未知结构退回原路径，规范恢复后才能重新建立可信基线。平面段落、嵌入、Mermaid 和修订重建
保留原有路径。验证覆盖本地/远端/Undo/Redo、其它行的同长原生污染以及三引擎 IME/选区边界。

## 第一阶段实施规则

1. 按实际 CRLF/LF 切分逻辑行，缓存行文本、tokens 及语法检查点。首次每 64 行调用一次 Shiki，保存段尾 grammar state，避免逐行调用的初始化成本。编辑时从变更行之前最近的检查点开始逐行解析并细化缓存；后缀文本与已知语法状态同时收敛后复用后续行，同一局部后续输入通常只需重算一行。跨行注释/字符串允许传播至文末，不能硬截为单行。
2. 语言或主题变化使语法缓存失效；销毁释放缓存。未变 token 行同时复用派生 Delta、行文本和指纹，避免再次为全文分配展示对象和计算指纹。纯文本走无需语法引擎的路径。Mermaid 特有的围栏兼容策略保留。
3. 用户颜色、隐藏和修订归因每次仍从当前模型展示属性投影；按有序区间线性合并，不缓存为语法状态。
4. 同步 render、applyDelta 和语言/主题切换立即使在途高亮失效。异步完成后检查生命周期、连接状态、代际和本块 IME 状态；其他块的组合输入不取消当前块高亮，旧结果不得覆盖新模型。
5. 高亮写回前读取当前 anchor/head，写回后恢复双端和方向；原生选区尚未归一化时优先当前原生端点，IME 尾部未托管节点仍由模型坐标兜底。折叠光标只做一次位置映射，未改变的选区不重复写入浏览器。整块选中及外部焦点不被高亮抢占，跨块范围保持原有边界。
6. 完整模型重建使 DOM 高亮基线失效，保证相同语法结果仍能重新上色。IME 的同步恢复复用已经加载的引擎，从完整模型快照（含已进入 Y.Text 的远端变更）生成高亮和修订投影；前后缀只有在文本、指纹、叶子结构及属性均一致时才能复用。`CodeLineIntegrity` 检查原生输入拆分的 Text、多余节点和被移除的修订属性，清理非托管残留并修复 gap/Break。检查不读取布局，属性投影缓存有上限；共享 Input 的事务、相对位置、延迟协同和撤销流程保持。
7. 行模式将跨 LF 的 TextBlot 拆成对应叶子，保留 CRLF 和 UTF-16 长度；复用未改行的 wrapper 和叶子。首 gap 放首行，BreakBlot 放末行，空文本/末尾 LF 有独立空行。隐藏修订 LF 不拆显示行，仍保留模型长度。
8. 行号仅由 `c-line` CSS counter 生成；移除 `d:lineBreak` / `data-line-break` 及首 token 特判。自动折行不增加逻辑行号；聚焦显隐行为保持。复制仍取模型正文。
9. Input 的 end-break 兼容路径允许末行 BreakBlot 没有前置 sibling，沿用已有事务写入及光标恢复，避免首次键入丢失。
10. Firefox 的跨行结构性 Backspace 范围可能映射成同一 offset。仅在相邻注册行及前一字符为可见 LF 时，转成原有删除 LF 的范围计划，先检查权限再执行；普通段落和词/行删除不介入。
11. 行删除先确定保留 wrapper，避免移动未变的后缀行；大范围高亮 `spliceLeaves` 一次重建叶子数组，消除逐叶数组 splice/indexOf 的二次复杂度，保留 Cursor/Break 与 embed 清理语义。

## 后续边界

分段覆盖词法缓存、持久 DOM 行容器和源逻辑行派生索引，没有块内虚拟化。普通单行修改不再读取未变叶子的文本/长度或重建全部行分组，仍保留完整模型读取和文本一致性比较、按行指纹比较及扁平数组引用移动。跨行、布局和原生异常恢复继续走完整路径；进一步优化需覆盖段落、嵌入、绕图、分页、IME 和跨浏览器原行为。

## 编辑、撤销重做与协同压力回归（2026-11-06）

压力用例使用固定种子与独立字符串结果，明确切开每次历史动作，不能据此推断普通连续键入
会生成同样数量的 Undo item。内容含中文、emoji/UTF-16、删除与替换、CRLF、首尾空行、
跨行注释与模板字符串。同步阶段直接核对模型与 DOM；稳定后检查双端模型/原生光标，
语法变化和完整历史终点另以全文 Shiki 解析比对颜色，避免只验证增量缓存自身。

- `e2e/code-block-stress.spec.ts`：1000 行 40 次混合编辑及全部撤销/重做；1000 行 24 次快速编辑，
  与完整历史及额外交错 Undo/Redo 在同一 JS 任务中执行，制造过期异步高亮；5000 行 24 次编辑及全部历史。
  检查每行内容、`c-line`、首 gap、末 Break、旧行号属性消失，以及最后显式导航不被旧恢复覆盖。

压测实际发现并修复了三处时序缺陷：

1. 连续撤销/重做时，原恢复流程延后发布模型选区，下一次操作捕获到临时空值；旧任务也可能覆盖新导航。
   `SelectionHistoryRestorer` 对可解析目标立即发布模型选区，DOM 未就绪仍经过原有投影重试，
   未挂载目标保留有界恢复，并让后续选区优先。Yjs 观察器前清选区和相对书签格式保持。
2. 折叠光标处取消 IME 时，`InputTransformer` 捕获了不会被任何文字事务消费的撤销快照，
   下一次在别处输入后撤销会回到取消位置。现在只有非空提交才预捕获；取消的 DOM 恢复、
   光标、延迟协同和会话清理，以及范围/结构替换的 capture group 保持。
3. 跨段 IME 撤销后，中间块的模型先于视图恢复，固定工具栏的分栏可用性探测直接取该视图而抛错。
   分栏 resolver 现在在任一目标视图缺失时整体返回不可用；不转换部分选区，也不强制挂载整个范围。
   全部视图就绪后仍执行原有同父、连续、schema 和只读检查。
