# 编辑交互模式与浮动排版示例

## 插件配置注册方案（2026-11-10）

- 原生配置由 Document 定义，插件通过 `DocPlugin.interactionConfigs` 声明自己的命名空间、字段、默认值、预设值与调试标签。核心解析器不引用插件实现，不维护插件字段清单。
- 每个 Doc 持有独立注册表。构造时先收集 `DocConfig.plugins` 的全部声明，再校验初始覆盖；插件 `init()` 前配置已就绪，不受初始化顺序影响。直接 `plugin.register(doc)` 的后装插件先原子注册声明；同一实例重复登记不产生重复通知，不同声明占用同一命名空间报错。
- 支持布尔、枚举、数值和文本字段，通过字段类型、枚举选项、数值范围/整数约束、文本长度校验。未注册命名空间/字段拒绝，不静默保存无效配置。声明和有效快照复制并冻结，默认值 < 模式预设 < 用户覆盖。
- 插件用声明对象读取类型化配置，监听沿用 `policyChanges$`。配置声明仅管理交互意图；插件构造参数、只读/锁、选区、输入和内容命令边界保持。
- 注册表与 Doc 同生命周期，当前无独立插件卸载协议；后装插件需要先注册，再设置其覆盖。配置不会安装插件。调试台根据实例中的声明生成表单，未安装插件不显示。
- 验证第三方插件不改核心/调试台即可出现新选项；覆盖初始化顺序、动态注册、重复与无效声明、原子失败、实例隔离、模式切换、校验、输入/拖动保护以及原有三模式交互。

## 交互配置领域方案（2026-11-10）

Document 的本地交互服务统一持有 `{preset, overrides}`，解析出只读 `policy`。预设是可复用的配置值，插件和原生功能不再判断模式名。旧 `interactionMode` API 保留为同一服务的别名，不引入第二份状态。

- 原生策略：布局控件显隐、悬停反馈、内部文字聚焦缩放抓手、已有块移动、组合边框。可见性与移动行为分开；缩放抓手显隐不是内容修改权限。
- 插件策略：对象格式、图片、内容区域各自配置内部选区触发；组合工具栏独立开关。组合不会继承成员选区，此规则属于工具栏归属，不是模式特例。已有整块工具栏及 callout 正文工具栏保持原语义。
- 配置仅管理本地交互意图。Readonly/锁定仍由原权限服务裁决，Selection 保持模型选区，Input 保持文字与 IME 输入，Placement/DragDrop 执行几何与排序，Plugin 负责 overlay 生命周期，Theme 只消费投影属性。
- 切换预设清空覆盖；`setOverrides()` 替换覆盖，空对象恢复预设；`configure()` 原子替换配置。实例内配置不会写入文档、Undo、协同或浏览器存储。
- 配置修改先校验再提交，IME、指针或移动会话中拒绝修改。只读快照、单次解析和单次通知避免高频重复合并；不增加指针移动时的 DOM 测量。
- 验证默认三模式兼容，以及混合加内部工具栏、设计关闭悬停、可见控件但禁止移动、组合框与组合工具栏分离、恢复预设、只读与实例隔离。

## 领域边界与不变量

- Document 通过 `interaction` 持有本地预设与覆盖，默认 `mixed`；`interactionMode` 为兼容别名，不写 Yjs、快照或撤销历史。
- Selection 独占选区与 `.focused` 投影；Placement 负责浮动移动；DragDrop 负责文档流排序；Input/CompositionSession 保留原文字输入路径。
- 不新增定位类型，不转换块结构，不改变只读、锁、协同及撤销权限。
- 模式入口位于 Playground 左侧状态区下方。固定工具栏不放模式切换，宿主可通过同一 API 接入。

## 交互规则

| 模式 | 正文与对象文字 | 对象控制 |
|---|---|---|
| 混合 | 直接输入、划选 | 悬停不显示对象边框/抓手；内部聚焦保留轻量入口，整块选中后显示完整控制点 |
| 沉浸 | 直接输入、划选 | 收起布局控制点和块抓手，禁止已有对象移动；保留内容、格式和媒体操作 |
| 设计 | 正文、表格、文本框、艺术字等均直接编辑 | 文本对象聚焦时显示八向抓手；对象内部选区显示对应浮动工具栏，组合除外 |

设计模式不会把正文单击改成整块选择，也不另行接管 Enter、Esc、方向键、IME 或表格操作。文字光标与缩放抓手可以同时存在；边框移动、缩放、取消、撤销沿用原有对象交互。通过原 Selection 的 `.focused` 类显示对应对象控制点，不伪造对象选区。锁定/只读对象不显示可编辑控制点。

对象工具栏以模型选区两端归属的最近对象为目标，同一对象内跨段落仍有效，跨对象或 gap 不推定归属。文本框、艺术字、形状、图片说明、内容区域复用各自工具栏；组合只在整组选中时显示组合菜单，内部成员可显示自己的工具栏。该判断仅在 Plugin 层生效，不扩展格式服务的整块选区语义，也不把艺术字文字光标投影成整块选中。内部选区格式操作走普通用户事务，提交时仍保留的文字选区会记录到 Undo。

切换模式不主动改选区、不改变滚动位置。IME 组合输入、按住指针、排序和移动会话期间拒绝切换。只读时暂停模式覆盖，解除只读后恢复当前模式。

沉浸模式同时隐藏组合操作浮动工具栏、组合整体边框、成员聚焦引出的组合边框及边缘移动热区；切入模式会关闭已打开的组合工具栏，切回混合/设计后按当前选区恢复。组合内部文字仍按原路径编辑。

## 调试页面

五档刻度拨杆使用单一 Pointer Events 提交路径：拖动只预览，松手提交一次；不叠加原生 range 的 input/change 提交。拖动区域禁用浏览器滚动手势，保留方向键、Home/End、PageUp/PageDown 与 Escape 取消，以及 slider ARIA 语义。只读和输入/对象拖动期间的配置保护继续生效。

2026-11-10 滑轨复核：新增浮动模板中间档位连续快速拖动场景，三浏览器共 18 项通过，覆盖松手后档位保留、轨道外松手、取消、键盘、选区和 Undo 不变。此前实现的相同快速拖动在三浏览器也通过，尚未在用户当前浏览器会话中捕获本次回跳的确切事件；本次收敛消除了两套提交路径，不能据此声称已复现该会话故障。真实触屏手势和屏幕阅读器尚未验收。

已移除外置“宿主文档头 · root 外部”及其分页接线。流式编辑区默认跟随外部容器宽度，取消固定 794px 文档列；分页纸张仍由分页插件管理。文档缩放继续使用原视图服务。

左侧「打开浮动排版模板」在独立页面打开 `/?example=floating-layout`，自动初始化示例，不覆盖当前文档。刷新示例页会重新载入初始模板；当前编辑不会自动持久化，可使用已有快照/导出入口留存。

## 城市更新提案：原生能力映射

| 区域 | 原生结构与定位 | 编辑方式 |
|---|---|---|
| 封面标题与导语 | 流式文本框预留封面高度，内部普通段落 | 直接编辑文字 |
| 纸色背景与圆形装饰 | 根级浮动 `under` 形状 | 通过对象布局工具调整 |
| 建筑插画 | 本地 SVG 图片块，根级浮动、轻微旋转 | 可移动、缩放、旋转；图中不包含正文 |
| RE:COMMONS | 独立浮动艺术字 | 直接编辑，设计模式显示抓手 |
| 编号、侧标与便签 | 独立浮动文本框，包含旋转、透明填充、阴影 | 文字可编辑，各对象可独立调整 |
| 工作室标识 | 浮动组合，成员使用局部坐标 | 组合整体移动，成员保留原生结构 |
| 两栏叙述与原则 | 流式分栏 + 文本框 | 正文增长沿用分栏布局 |
| 阶段路径 | 流式组合，局部浮动形状与文本框 | 整体随正文移动，组内可编排 |
| 阶段表 | 原生 4×4 表格，自动列宽 | 单元格直接编辑 |
| 现场札记 | 正文 + 行内环绕图片 | 文字绕图，正文继续增长 |

封面对象使用固定设计坐标，不承诺在窄容器或分页裁切时自动重排；流式编辑器宽度跟随容器不等于把浮动版式自动缩放。示例不接入业务数据或外部资源请求。
