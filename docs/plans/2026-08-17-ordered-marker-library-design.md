# 有序块编号符号库设计

## 目标

让现有 `ordered` 块像 Word 一样，从编号库中选择多种标记外观，同时保持：

- 旧文档不写新字段，继续按 `depth` 使用数字 / 小写字母 / 小写罗马数字轮换；
- 编号仍由 `order` / `start` 负责，符号样式不参与计数；
- 编辑器、Snapshot Viewer 与 HTML 往返共用同一套格式定义；
- 修改以自动编号的“编号组”为作用域：同层普通段落不分组，结构剪枝或显式重新编号才分组。

## 领域边界

编号能力拆成三个互不混用的概念：

1. **Counter**：`OrderedBlockPlugin` 维护 `order`，决定当前是第几项。
2. **Marker**：`ms`（marker style）决定把序号显示成 `1.`、`(1)`、`A.`、`一、` 等形式。
3. **Numbering Group**：样式命令的作用域。一个编号组复用 Counter 的 `depth + heading` 与结构剪枝规则；它可以跨过同层普通段落和组内其他层级。返回更浅层、跨越相关标题边界或遇到同一 Counter 的显式正数 `start` 时才分组。

Marker 不进入 `Y.Text`，不参与 IME、文本选区或 inline formatting。它是从块 props 到展示 DOM 的纯投影。

## 持久化契约

`ordered.props.ms?: OrderedMarkerStyleId | null`。

- 缺省 / `null`：保留历史的按层级轮换行为；
- 有效 ID：使用编号库中的固定定义；
- 未知 ID：渲染时按缺省处理，防止旧客户端或损坏快照抛错；
- 新建列表项从来源项或它加入的自动编号组继承有效 `ms`，`order` / `start` 仍由插件维护。

首批预设：

`1.`、`1)`、`(1)`、`1、`、`01.`、`a.`、`A.`、`i.`、`I.`、`一、`、`壹、`、圈号。

## 命令语义

- 光标位于有序块：更新当前编号组的当前 Counter 层级；
- 多块选择：对选择覆盖到的每个编号组各执行一次；
- 光标位于普通可编辑块并从编号库选样式：转为 `ordered` 时直接把选中的 `ms` 写进新快照，避免依赖异步选区恢复；
- 普通“有序列表”主按钮只负责转块/取消列表，不偷偷指定新样式；
- `Continue / Restart` 只改变计数边界，不改 `ms`。

所有批量样式写入使用一个普通 Yjs transaction，进入 Undo；自动 `order` 修复继续使用 `ORIGIN_SYSTEM_REPAIR`，不进入 Undo。

## UI

固定工具栏把有序列表做成分体按钮：

- 主按钮：有序列表开关；
- 箭头：打开编号库；
- 预览面板：3 列网格，显示真实的前三个编号，不使用图片或独立图标资源。

点击文档中的编号仍只打开原来的“继续编号 / 重新编号 / 重新计算”控制面板；编号样式不放进这个浮动 Toolbar，避免入口重复和面板过重。

## 导出与兼容

- HTML：不输出私有编号样式字段；五种标准样式输出 `<ol type="1|a|A|i|I">`，其余降级为普通编号；
- HTML 导入：只读取父 `<ol type>`，不识别 BlockCraft 私有编号样式字段；
- Markdown：标准语法没有这些外观，继续退化为普通有序列表；
- Snapshot Viewer：调用与编辑器相同的 `resolveOrderedMarker()`，不维护第二套 formatter。

## 性能与兼容性

- 单个标记格式化只与数字位数有关，不做 DOM 查询；
- 编号组扫描只在用户执行样式命令时发生，复杂度为当前父节点直接子块数 `O(n)`；
- 高频输入、scroll、selectionchange 和 Yjs observe 热路径不增加扫描；
- 圈号由 CSS 绘制紧凑正圆，单个数字也缩到普通编号的视觉字高以内；位数增加时继续缩数字，不改变圆形几何，打印保留描边；
- Angular 组件保持 `standalone + OnPush`，Overlay 生命周期仍由现有指令/Plugin 管理。
