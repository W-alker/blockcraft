# 艺术字内部滚动与浮动工具栏焦点修复设计

## 背景

艺术字块当前存在两个相关但职责不同的问题：

1. 在艺术字内部选中文字并向上或向下拖动时，浏览器会滚动内部编辑元素，导致文字相对蓝色变换边框发生偏移。
2. 聚焦浮动工具栏里的输入框时，原生输入控件会让编辑器选区暂时清空，艺术字工具栏插件将这一状态误判为离开艺术字并立即销毁工具栏。

这两个问题都应在艺术字自身的布局和工具栏交互边界中修复，不改变编辑器全局选区规则。

## 目标

- 艺术字文字与蓝色变换边框始终使用同一视觉坐标，不允许内部滚动造成相对偏移。
- 浮动工具栏中的数字、颜色和滑杆输入框能够正常获得焦点并连续操作。
- 工具栏输入期间不抢回艺术字文本焦点，不重放浏览器原生选区。
- 选择其他块、点击工具栏和艺术字之外的区域，或艺术字失效时，工具栏仍正常关闭。
- 不影响艺术字拖动、缩放、旋转和文本编辑行为。

## 非目标

- 不修改 `SelectionManager` 对原生输入控件的全局处理规则。
- 不重新设计浮动工具栏的视觉样式或控件结构。
- 不改变艺术字块的公开数据结构、插件注册方式或外部 API。

## 方案

### 1. 禁止艺术字编辑区产生内部滚动

将艺术字编辑元素从 `overflow: hidden` 调整为真正禁止滚动的 `overflow: clip`。`hidden` 只隐藏滚动条，元素仍是可滚动容器；浏览器在拖动文本选区时仍可能修改它的 `scrollTop` 或 `scrollLeft`。

为兼容不同浏览器的原生选区行为，艺术字块对编辑元素增加防御性滚动归零：

- 仅监听艺术字内部编辑元素自身的 `scroll`。
- 发现非零 `scrollTop` 或 `scrollLeft` 时立即归零。
- 监听在 Angular 变更检测之外执行，并在组件销毁时移除。
- 不监听文档外层滚动容器，不重新计算绝对定位坐标。

这样蓝色变换边框和文本仍由同一个 surface 布局，修复只作用于产生偏移的内部滚动层。

### 2. 将浮动工具栏纳入艺术字交互所有权

艺术字工具栏插件保留当前活动艺术字块，并把工具栏 overlay 视为该块交互的一部分。

具体规则：

- 指针按下发生在工具栏内部时，先标记一次“工具栏交互正在开始”，避免原生输入聚焦前的选区清空触发关闭。
- 焦点位于工具栏 overlay 内部时，即使编辑器选区暂时变为 `null`，也继续保留工具栏。
- 工具栏存续期间继续显示艺术字的蓝色变换框，但不把 DOM 焦点从输入框抢回文本编辑区。
- 工具栏输入框获得焦点后，不主动恢复艺术字文本选区，也不将焦点移回编辑器。
- 选区切换到其他块时立即关闭当前艺术字工具栏。
- 焦点和指针均离开艺术字及其工具栏，且没有恢复为当前艺术字选区时关闭工具栏。
- 活动艺术字块被删除、变为只读或引用失效时关闭工具栏。

状态判断由艺术字工具栏插件自身负责，不扩大全局 `SelectionManager` 或 `OverlayService` 的职责。

## 状态与时序

### 聚焦工具栏输入框

1. 用户在工具栏输入框上按下指针。
2. 插件在捕获阶段记录工具栏交互。
3. 浏览器聚焦原生输入框，编辑器选区可能清空。
4. 插件发现交互或焦点仍属于工具栏，保留 overlay。
5. 输入控件继续接收键盘、滑杆或颜色操作。

### 离开工具栏

1. 用户选择其他块时，新的块选区直接关闭旧工具栏。
2. 用户点击编辑器外部且焦点不再属于工具栏时，插件在焦点/指针状态稳定后关闭工具栏。
3. 用户重新点击同一艺术字时，沿用正常选区路径，不创建重复 overlay。

## 边界条件

- 工具栏内部下拉层若渲染在同一 overlay 容器外，需要通过现有工具栏交互标记而非单纯 `contains(activeElement)` 判断，避免点击下拉项时误关。
- `focusout` 的关闭判断应延迟到浏览器完成焦点迁移之后，防止 `relatedTarget` 不可靠或尚未更新。
- 内部滚动归零不触发 Yjs 数据写入，因为它只修复瞬时 DOM 滚动状态，不改变文档内容。
- 高频滚动监听不得触发 Angular 变更检测或同步读取布局尺寸。

## 验证

### 自动化测试

- 模拟艺术字编辑元素产生非零滚动，验证横纵滚动均归零。
- 选区清空但工具栏输入拥有焦点/交互所有权时，overlay 不被关闭。
- 选区切换到其他块时，overlay 被关闭。
- 工具栏交互结束并真正离开后，overlay 被关闭。
- 重复进入同一艺术字不会创建重复 overlay 或重复监听。

### 浏览器回归

- 选中文字后向上、向下拖动，文字不再相对蓝框移动。
- 数字、颜色和 range 输入均可聚焦，工具栏不会消失。
- 输入期间艺术字文本不被抢焦点。
- 点击工具栏外部、选择其他块后正常关闭。
- 缩放、旋转、边框拖动和文本编辑维持现有行为。

## 性能与兼容性

- CSS 优先阻止滚动，JavaScript 只作为非零内部滚动的低成本兜底。
- 监听器绑定在单个艺术字编辑元素上并在销毁时清理。
- 不在滚动路径中调用 `getBoundingClientRect` 等同步布局查询。
- 使用插件局部状态维护工具栏焦点边界，避免影响所有块和原生输入控件。
