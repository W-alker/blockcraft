# 布局与对象：按内容寿命选承载方式

> Last updated: 2026-10-08

## 决策表

| 需要 | 首选 | 何时改用另一种 |
| --- | --- | --- |
| 普通标题、正文、署名、随文信息 | paragraph / 原生列表 / 行内材料 | 需要独立框体、旋转、位置才用对象 |
| 左标签右正文或并列内容 | columns + column | 窄宽仍要读时先验证分栏宽度；不支持自动折叠就改纵排 |
| 一段内容共同底色、边框或填写语义 | render-unit 等宿主已开放的流式容器 | 没有共同表面或业务语义时直接段落，不额外包壳 |
| 有固定尺寸的便笺、说明牌、侧注 | text-box，内部使用普通段落 | 长篇主要正文改用流式；框内标题不再套第二个框 |
| 丝带、气泡、几何徽章 | shape，优先原生目录预设 | 原生没有对应图案时使用独立图片，不用大量小形状拼花纹 |
| 少量强调性文字 | word-art 或有文字效果的原生对象 | 普通正文和可增长标题仍用段落；不要默认所有标题都是艺术字 |
| 花束、邮票、复杂多色装饰 | 独立 image / 可用的 sticker | 重复纸纹、无须独立移动的底纹才合入纸张背景 |
| 花牌和日期卡要共同移动缩放 | object-group | 只因颜色相似、位置相邻或同属页头，不足以组合 |
| 跨模块的独立线条 | divider | 紧随某标题的左右/上下装饰线用该段落 decoration |

这是设计选择，不是 Agent 的可写白名单。object-group、placement-layout、sticker 等须确认本次宿主暴露了操作，不能从表格推导出可创建的能力。

## 文档流、固定对象和混合布局

流式模式允许页面宽度变化；文本框、形状、组合块的固定几何不会自动获得网页的响应式断点。绝对对象也不会因前面的正文增长而自然下移。

- **流式文档**：主信息按阅读顺序纵向组织。装饰不承担栏目位置；少量相对流式对象也要验证最窄宽度。长文自动扩展，不靠大量空行、隐藏溢出或缩字装下。
- **固定纸张**：先确定纸张、边距、可用正文矩形，再安排对象。固定四张卡片可以保留构图，但删除一张会留下位置，不承诺自动补齐。
- **混合**：正文标题走文档流，角落花牌作为独立对象；花牌内图和日期卡共同移动时才组合。别把标题与装饰锁在同一个大组合中。

可删除栏目用自包含的标题与正文；不用写死的连续序号，除非需要用户可维护的编号或当前原生列表可处理。删除后自然紧凑和固定画布构图是不同目标，按用户目标取舍。

## 坐标、层次与组合

完整编辑器中，绝对对象归属 placement-layout，组合成员位置相对组合；position 不是浏览器屏幕坐标，也不是 CSS 的 sticky/fixed。置于页顶表示相对页面布局，不能称为滚动吸顶。

公开几何操作归属 `doc.placement`，如 `insertAbsoluteSnapshot`、`updateObjectGeometry`、`group/ungroup`；使用前查当前签名和宿主可用性。不要只加 position 就假设块已脱离文档流。屏幕测量值要按当前 geometryScale 转回布局单位，并扣除正确原点；不要把截图 70% 缩放值直接保存。

组合保持共同几何，不提供自动响应式布局。组内文本用原生 text-box 等明确支持可编辑文本的对象；普通流式容器不因为能显示就适合塞进组合。组合内日期、天气等可能等比缩放，文本框可能重排，验证实际结果。

## 文本框尺寸诊断

外框高度约等于实际文本行盒高度之和 + 段间距 + 上下文字内边距 + 形状文字安全区。矩形之外的形状可能先内缩文字矩形，再叠加用户 padding；padding 为 0 不一定贴边。

出现“字下方很空”时，依次看初始 height、父级 textFont/textSpacing、子段落 lh/psa、textPadding 和形状安全区。不要只设垂直居中或全局改段落 CSS。autoFit 是否会缩小已有大框、允许哪些值，以当前实现为准，不承诺自动收紧。

单行标签以实际行高定框，而不是套用正文卡片默认高度。多行/中英混排再检查基线与换行。尺寸下限可能把圆形标签撑成椭圆，不能照搬 HTML 的小徽章像素值。
