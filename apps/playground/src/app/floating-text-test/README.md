# 浮动文字测试页

启动 Playground 后打开 `/tests/floating-text`；添加 `?scale=stress` 切换压力场景。主 Playground 的“浮动文字测试”按钮也可进入。

```sh
pnpm exec ng serve playground --configuration development --port 8087 --host 127.0.0.1
```

- 普通场景：60 个固定文本框、4 个自适应文字对象、1 个含自适应文字的组合。
- 压力场景：1000 个固定文本框、24 个自适应文字对象、1 个含自适应文字的组合。
- 使用真实 EditorComponent、内置插件与独立 Y.Doc，不连接协同服务，不保存测试修改。

建议操作：

1. 点击“从主文本框下方开始”，在编辑区向上滚动，观察文本框尾部是否立即出现。
2. 跳到文档底部，切换长短文本，观察主文本框的自适应测量值。
3. 在底部将主文本框切换为固定尺寸，应变为“未挂载”；再恢复内容自适应，应立即挂载。
4. 定位主文本框，点击文字输入，检查撤销、重做及编辑器的对象工具栏。
5. 切换压力场景反复上下滚动，检查固定对象数量随位置变化，自适应样本与组合保持挂载。

计数仅跟踪预置样本，按实际挂载对象统计，每 150 ms 更新；不扫描全量模型或在滚动统计中读取几何尺寸。主文本框切换模式后仍计入原来的样本组。选区可能保留对象挂载，可点顶部／底部按钮清除选区后再观察。新增、删除、拆组会改变样本状态，刷新可恢复初始文档。此页用于交互验证，计数不代表生产环境帧率基准。

## 定向验证（2026-10-12）

Chromium、Firefox、WebKit 均验证了普通／压力场景加载、从下方进入文本框、离屏长短文本切换、固定／自适应切换、键盘文字输入及撤销重做；同时检查了 800px 窗口布局，未捕获页面异常。此处键盘输入使用英文字符，不代表系统中文输入法验收。

页面点击编辑时发现并修复了间隙插件读取可编辑段落 `childrenIds` 的异常：新增用例修改前失败，修复后插件 19 项测试全部通过，保留容器空白区与浮动对象原有间隙行为。
